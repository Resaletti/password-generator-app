# Secure Password Generator

Modern responsive password generator application built with JavaScript featuring customizable password creation, clipboard functionality, and clean UI design.

---

## 🚀 Project Overview

This project was developed to demonstrate front-end development fundamentals, user interaction handling, responsive design principles, and JavaScript-based dynamic functionality.

The application allows users to generate secure passwords with customizable options and modern visual feedback.

---

## ✨ Features

- Secure random password generation
- Adjustable password length
- Uppercase and lowercase support
- Numbers and special characters
- Copy-to-clipboard functionality
- Responsive modern UI
- Interactive user experience

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Design
- Vite
